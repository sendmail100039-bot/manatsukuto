# ココナラ出品パッケージ（AI活用レッスン）

ココナラで「AIの使い方を教える」サービスを出品するための原稿・進行台本・運営手順の一式です。
出品画面にそのままコピーできる形で書いています。

## 前提として確定した条件

| 項目 | 内容 |
| --- | --- |
| 出品形態 | ビデオチャット（画面共有）によるマンツーマン授業 |
| 構成 | 1時間 × 3単位（第1回 導入 → 第2回 開発 → 第3回 運用） |
| ターゲット | AI未経験の個人 |
| 価格帯 | 1コマ 5,000〜10,000円（立ち上げ期は下限、実績後に適正化） |
| ブランド | MANATSUKUTOとは切り離した個人名義の出品 |

ブランドを分ける判断は、ココナラが**プラットフォーム外への誘導・連絡先交換を禁止**しているためでもあります。
出品文・レッスン中ともに、自社サイト名やメールアドレスを出さない前提で全原稿を書いています。

## ファイル構成

| ファイル | 用途 |
| --- | --- |
| [`01-service-listing.md`](01-service-listing.md) | 出品ページの原稿一式（タイトル、キャッチコピー、サービス内容、購入にあたってのお願い、有料オプション、FAQ、価格） |
| [`02-curriculum.md`](02-curriculum.md) | 全3コマの進行台本（分単位の流れ、到達点、宿題、画面共有で見せるもの） |
| [`03-operations.md`](03-operations.md) | 運営手順（当日運用、規約上の注意、実績ゼロからの立ち上げ計画、価格改定の基準、トラブル対応） |
| [`04-templates.md`](04-templates.md) | 定型文テンプレート（事前アンケート、開始前案内、当日、フォロー、評価依頼、お断り文面） |

## 使い方

1. `01-service-listing.md` のタイトル案から1つ選び、出品画面に入力する
2. `03-operations.md` の「立ち上げ計画」に沿って、まず価格を立ち上げ期の設定にする
3. 購入が入ったら `04-templates.md` の定型文で事前アンケートを送る
4. 当日は `02-curriculum.md` を手元に開いたまま進行する

## 注意

ココナラの仕様（カテゴリ名、文字数上限、手数料率、ビデオチャットの機能）は変更されることがあります。
本文中で **［要確認］** と書いた箇所は、出品前に必ずココナラの管理画面・ヘルプで最新の内容を確認してください。
