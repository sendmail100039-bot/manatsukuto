# リハーサル研修 一式（取り決め書・実施記録・アンケート）

ココナラで最低金額の枠を使う**前**に、知人を相手に全3回を通しで実施し、カリキュラムの穴を潰すための書類です。

この研修は**ココナラを介さず、当事者間で直接実施します**。プラットフォームを経由しないため、
出品・評価・手数料のいずれとも無関係です。

---

## 1. 取り決め書（印刷して2部作成、双方が1部ずつ保管）

> 貸付金の残額や返済条件を扱うため、金額が大きい場合や相手方に異論がある場合は、
> 署名前に弁護士等へご確認ください。本書は当事者間の合意内容を記録するための書式であり、
> 法的助言ではありません。

```text
　　　　　　　研修の実施および貸付金の一部減額に関する確認書


甲（研修を行う者）　氏名：＿＿＿＿＿＿＿＿＿＿＿＿
乙（研修を受ける者）氏名：＿＿＿＿＿＿＿＿＿＿＿＿


第1条（貸付金の確認）
　甲乙は、本書の作成日時点において、甲が乙に対して有する貸付金の残額が
　金　＿＿＿＿＿＿＿＿　円であることを相互に確認する。

第2条（研修の実施）
　甲は乙に対し、次の内容の研修を実施する。
　　名称：AI活用の基礎研修
　　回数：全3回
　　時間：1回あたり60分
　　内容：第1回 導入 ／ 第2回 開発 ／ 第3回 運用
　　方法：対面またはオンライン（実施の都度、双方で決定する）

第3条（減額）
　甲は、第2条の研修を1回実施するごとに、第1条の貸付金残額から
　金　＿＿＿＿＿＿　円を減額する。
　全3回の実施により、減額の合計額は金　＿＿＿＿＿＿　円となる。

第4条（減額後の残額）
　全3回の研修終了後の貸付金残額は、金　＿＿＿＿＿＿＿＿　円となる。
　乙は、当該残額について支払義務があることを確認する。

第5条（返済）
　前条の残額の返済方法および期日については、
　　□ 別途協議のうえ定める
　　□ 　＿＿＿＿年＿＿月＿＿日までに一括して支払う
　　□ 毎月＿＿＿＿＿円ずつ、＿＿＿＿年＿＿月から支払う
　（該当する項目にチェックする）

第6条（研修の性質）
　1. 本研修は、乙の知識および技能の習得を目的とするものであり、
　　 特定の成果、収入または資格の取得を保証するものではない。
　2. 本研修において扱うAIの出力内容について、甲はその正確性を保証しない。
　　 乙は、業務等に用いる際、自らの責任において内容を確認するものとする。
　3. 甲は本研修において、医療、法律、税務および会計に関する個別の判断または
　　 助言を行わない。

第7条（研修の記録および感想の利用）
　1. 甲は、本研修の実施内容を記録することができる。
　2. 甲は、乙が任意に提出した感想を、甲の事業の紹介資料等に掲載することができる。
　　 ただし、掲載にあたっては、掲載する文面および表示する氏名の範囲について、
　　 事前に乙の同意を得るものとする。
　3. 乙は、前項の掲載についていつでも撤回を求めることができ、
　　 甲は速やかにこれに応じる。

第8条（中止）
　いずれの当事者も、理由を問わず本研修の継続を中止することができる。
　この場合、既に実施された回数分の減額は有効とし、未実施分については減額を行わない。

第9条（協議）
　本書に定めのない事項または疑義が生じた事項については、甲乙誠実に協議して定める。


　本書2通を作成し、甲乙記名押印のうえ、各1通を保有する。


　　　　　　　　　　　　　　　　　　　　　　　　＿＿＿＿年＿＿月＿＿日


　　　甲　住所：＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿

　　　　　氏名：＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿　　　　　　㊞


　　　乙　住所：＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿

　　　　　氏名：＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿＿　　　　　　㊞
```

### 第1条・第4条を必ず埋める理由

個人間の貸金は、借用書がないと金額も時期も後から争いになります。
**第1条で相手が残額を認め、第4条で減額後の残額に支払義務があることを確認する**構成にしてあります。

「借用書を書いてくれ」と単独で切り出すより、研修の取り決めの一部として自然に作れます。
回収を諦めていた債権について、少なくとも金額の記録が残ります。

## 2. 実施記録（取り決め書の裏面または別紙として保管）

```text
　　　　　　　　　　　研修実施記録

　甲：＿＿＿＿＿＿＿＿＿＿　　乙：＿＿＿＿＿＿＿＿＿＿

┌─────┬──────────┬────────┬──────────┬──────────┬──────┬──────┐
│ 回  │ 実施日     │ 時間       │ 実施内容      │ 減額額     │ 減額後残額 │ 確認   │
├─────┼──────────┼────────┼──────────┼──────────┼──────┼──────┤
│ 1   │  /   /     │  :  〜 :   │ 導入         │      円   │      円  │ 甲   乙 │
├─────┼──────────┼────────┼──────────┼──────────┼──────┼──────┤
│ 2   │  /   /     │  :  〜 :   │ 開発         │      円   │      円  │ 甲   乙 │
├─────┼──────────┼────────┼──────────┼──────────┼──────┼──────┤
│ 3   │  /   /     │  :  〜 :   │ 運用         │      円   │      円  │ 甲   乙 │
└─────┴──────────┴────────┴──────────┴──────────┴──────┴──────┘

　　全3回終了時点の残額：金　＿＿＿＿＿＿＿＿　円

```

毎回その場で記入し、双方が確認欄に署名します。後日まとめて書かないでください。

## 3. カリキュラム改訂記録（甲側の控え／相手には見せない）

リハーサルの主目的はこちらです。**実施中ではなく、終了直後にその場で書いてください。**

```text
■ 第（　）回　実施日：　　/　　/

【時間】
　予定 60分 → 実際（　　）分　　超過・不足：（　　）分

【どこで時間を使ったか】
　0-15分：（　　　　　　　　　　　　　　　　　　　　　　）
　15-30分：（　　　　　　　　　　　　　　　　　　　　　　）
　30-45分：（　　　　　　　　　　　　　　　　　　　　　　）
　45-60分：（　　　　　　　　　　　　　　　　　　　　　　）

【詰まった箇所】※最重要
　1. （　　　　　　　　　　　　）で止まった　→ 原因：（　　　　　　　　）
　2. （　　　　　　　　　　　　）で止まった　→ 原因：（　　　　　　　　）

【通じなかった言葉】
　（　　　　）→ 次回の言い換え：（　　　　）
　（　　　　）→ 次回の言い換え：（　　　　）

【相手から出た質問】※出品ページのFAQに転記する
　Q.（　　　　　　　　　　　　　　　　　　　　　　　　　　　）
　Q.（　　　　　　　　　　　　　　　　　　　　　　　　　　　）

【到達点に届いたか】
　□ 届いた　　□ 一部　　□ 届かなかった
　届かなかった場合、何が足りなかったか：（　　　　　　　　　　　　　）

【次回までに直すこと】
　1. （　　　　　　　　　　　　　　　　　　　　　　　　　　　）

```

3回終わったら、この記録をもとに `02-curriculum.md` を書き換えます。
**時間超過が出た回は、必ず内容を削ってください。** 巻きで進める前提のカリキュラムは本番で破綻します。

## 4. 受講後アンケート（3回目の終了後に依頼）

サイト掲載用の「受講者の声」を、正当な形で取るための質問票です。
**ココナラの評価とは無関係**です。掲載は本人の同意を得た範囲でのみ行います。

```text
　　　　　　　研修を終えてのアンケート

お答えいただける範囲で構いません。空欄のままでも結構です。


1. 研修を受ける前、AIについてどんな状態でしたか。

　（　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　）


2. 受ける前に、不安だったこと・面倒に感じていたことはありますか。

　（　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　）


3. 3回を終えて、できるようになったことを教えてください。

　（　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　）


4. 一番わかりにくかったところ、説明が足りなかったところはどこですか。
　（改善のために使います。遠慮なくお書きください）

　（　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　）


5. 逆に、これは分かりやすかったという点があれば教えてください。

　（　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　）


6. どんな人にこの研修が向いていると思いますか。

　（　　　　　　　　　　　　　　　　　　　　　　　　　　　　　　）


7. 上記の内容を、事業の紹介資料やWebサイトに掲載してもよいですか。

　　□ 掲載してよい　　　　　□ 掲載しないでほしい

　　掲載してよい場合、表示するお名前：
　　□ 実名　　□ イニシャル　　□ 匿名（「50代・男性」等）　　□ その他（　　　）

　　※ 掲載後でも、いつでも取り下げを申し出ていただけます。


　　　　　　　　　　　　　　　　　　　　＿＿＿＿年＿＿月＿＿日

　　　　　　　　　　　　　　　　お名前：＿＿＿＿＿＿＿＿＿＿＿＿
```

### 掲載するときの注意

- **設問7で「掲載してよい」に印がないものは、一切掲載しない**
- 文章を編集する場合（誤字修正、長さの調整）は、本人に修正後の文面を見せて確認を取る
- 掲載時は「知人による受講」であることを伏せない。`受講者の声（研修モニター）` のように、
  どういう立場の人の感想かが分かる表記にする
- 設問4の否定的な回答は掲載義務がないが、**カリキュラムの修正には必ず反映する**

## 進め方の順序

```
　取り決め書に署名（第1条・第4条を埋める）
　　↓
　第1回 → 実施記録に署名 → カリキュラム改訂記録を書く → 修正
　　↓
　第2回 → 同上
　　↓
　第3回 → 同上 → アンケート依頼
　　↓
　02-curriculum.md を書き換える
　　↓
　ココナラで最低金額の出品を公開（01-service-listing.md 第0段）
```
