# 定型文テンプレート

トークルームにそのまま貼れる文面です。`（　）` の箇所を埋めて使います。
**いずれの文面にも、外部の連絡先・サイト名は入れないでください**（ココナラの規約上の理由。`03-operations.md` 参照）。

---

## A. 購入直後（当日中に送る）

```text
このたびはご購入いただき、ありがとうございます。担当の（氏名）です。

当日の内容をご希望に合わせて準備したいので、
お手数ですが下記5つの質問にご回答ください（3分ほどで終わります）。

1. AIを使ったことはありますか？
　　a) まったくない　b) 登録だけした　c) 数回使った　d) たまに使っている

2. 今、時間がかかっている作業や「面倒だな」と感じている作業を1つ教えてください。
　　（曖昧なままで構いません。「よく分からない」というご回答でも大丈夫です）

3. お使いのパソコンは Windows / Mac のどちらですか？

4. ご希望の日時を、第3希望までお知らせください。
　　（対応可能な時間帯：（　　　　　　　　　　））

5. 当日、特に不安な点や、ご要望があればお書きください。

ご回答をいただき次第、日程を確定し、当日の準備を進めます。
分からない項目は空欄のままで構いません。よろしくお願いいたします。
```

---

## B. 日程調整（回答受領後24時間以内）

```text
ご回答ありがとうございます。内容を拝見しました。

日時は （　月　日（　）　時　分〜　時　分） で確定させていただきます。

当日は、いただいた「（受講者が挙げた困りごと）」を題材に進めます。
終了時には、（　　　　　　　　　　）ができている状態を目指します。

ご準備いただくもの
・パソコン（インターネットに繋がる状態）
・特別なソフトの用意は不要です。ブラウザだけで進めます
・お仕事の機密情報や、他の方の個人情報が画面に映らないようご注意ください

当日は開始5分前を目安に、こちらからビデオチャットをお繋ぎします。
カメラのオンは必須ではありません。音声と画面共有のみで問題ありません。

それでは、当日よろしくお願いいたします。
```

## C. 前日リマインド

```text
明日 （　時　分）〜 のレッスンについてのご連絡です。

・所要時間：60分
・ご用意：パソコンとインターネット環境
・開始5分前を目安に、こちらからお繋ぎします

もし接続がうまくいかない場合も、慌てずこちらへメッセージをください。
開始時刻から5分ほどは接続の確認にあてる想定で進めます。

明日はどうぞよろしくお願いいたします。
```

## D. 受講メモ（終了後30分以内に送る）

**この文面の質が、評価とリピートに直結します。** 必ず当日中に送ってください。

```text
本日はありがとうございました。今日の内容をまとめてお送りします。

■ 今日できるようになったこと
・（　　　　　　　　　　）
・（　　　　　　　　　　）

■ 今日使った指示文（そのままコピーして使えます）
------------------------------
目的：（　　　　　　　）
相手：（　　　　　　　）
条件：（　　　　　　　）
形式：（　　　　　　　）
------------------------------

■ 次に試していただきたいこと
（　　　　　　　　　　）を、同じ手順で1回やってみてください。
うまくいかなくても問題ありません。「どこで詰まったか」が次回の材料になります。

■ 気をつける点（今日お伝えした内容の再掲）
・日付、金額、固有名詞、法令に関する記述は、必ずご自身で確認してください
・他の方の個人情報や、お勤め先の機密情報は入力しないでください

ご不明な点があれば、このトークルームでお気軽にお尋ねください。
```

## E. フォロー（翌日）

```text
昨日はありがとうございました。その後、いかがでしょうか。

お送りした指示文を一度お試しいただくと、定着しやすくなります。
うまくいかない箇所があれば、状況を教えていただければ回答します。

なお、次の段階として下記をご用意しています。ご検討いただければ幸いです。

・第2回（開発）：今日の内容をもとに、実際に使えるものを1つ完成させます
・第3回（運用）：繰り返し使える形に整え、今後の進め方を一緒に決めます

もちろん、今回だけで終えていただいても構いません。
```

## F. 評価依頼（クローズ時）

催促にならないよう、**1回だけ**にとどめます。

```text
このたびはご利用いただき、ありがとうございました。

もしよろしければ、今回のご感想を評価としてお寄せいただけますと励みになります。
「ここが分かりにくかった」というご指摘も、今後の改善に活かしますので歓迎いたします。

またお困りのことがありましたら、いつでもご相談ください。
ありがとうございました。
```

## G. 外部での直接取引を持ちかけられた場合

角を立てずに、しかし明確に断ります。

```text
ご提案ありがとうございます。
恐れ入りますが、ココナラの規約により、外部での直接のお取引やご連絡先の交換は
お受けできない決まりとなっております。

引き続き、こちらのトークルームからご依頼いただけますと幸いです。
継続してご利用いただく場合のご案内も、こちらでお出しできます。
```

---

## H. 対応できない相談を受けた場合

```text
ご相談ありがとうございます。
いただいた内容は、（医療 / 法律 / 税務 / 会計）に関する個別の判断が必要な領域のため、
こちらでは回答を差し控えさせていただきます。

その分野の専門家にご確認いただくのが確実です。
なお、「専門家に相談するための資料や質問事項を整理する」という形であれば、
AIを使ってご一緒に進めることが可能です。
```

```text
日程の変更を承ります。ご都合のよい日時を、第3希望までお知らせください。
（対応可能な時間帯：（　　　　　　　　　　））

当日の急なご予定は誰にでもありますので、お気になさらないでください。
```

## J. 時間内に終わらなかった場合（当日その場で）

```text
本日は、（　　　　　　）まで進めることができました。
残っている（　　　　　　）については、次のいずれかでご対応いたします。

・このトークルームで、手順を文章にしてお送りする（追加料金はいただきません）
・次回のレッスンの冒頭で続きから進める

こちらの進行の見積りが足りず、失礼しました。ご希望をお聞かせください。
```
