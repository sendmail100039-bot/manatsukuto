# 進行台本（全3コマ）

当日は本ファイルを手元に開いたまま進行します。**時間は目安**です。遅れたときにどこを削るかを各コマの末尾に書いてあります。

## 全体の到達点

| コマ | テーマ | 終了時の状態 |
| --- | --- | --- |
| 第1回 | 導入 | 自分の困りごと1つに対して、AIから使える答えを引き出せている |
| 第2回 | 開発 | 成果物が1つ完成している（文章・資料 または 公開されたWebページ） |
| 第3回 | 運用 | 繰り返し使えるテンプレートと、今後30日の計画が手元にある |

**設計上の原則**

1. 説明する時間より、受講者が操作している時間を長くする（目安：講師の話は合計20分以内）
2. 1コマにつき、必ず1つ「持ち帰れるもの」を残す
3. 「あとで送ります」を作らない。その場で完成させる
4. 未経験者は失敗すると止まる。**最初の10分で必ず一度、成功体験を作る**

---

## 第1回：導入（60分）

**目的**：AIを「触ったことがある」から「指示を出せる」に変える。

| 時間 | 内容 | 講師の動き |
| --- | --- | --- |
| 0-5分 | 挨拶・接続確認・画面共有テスト | 音声と画面が見えているかを先に確認。ここで詰まる人が一定数いる |
| 5-10分 | **いきなり1回やってみる** | 事前アンケートで受け取った困りごとを、講師が画面共有でAIに投げて見せる。結果が出るところまで見せきる |
| 10-20分 | 受講者のアカウント確認・初期設定 | 未登録なら一緒に登録。既にあれば画面を開いてもらう |
| 20-35分 | **指示の型を練習する** | 下記「指示の4点セット」を提示し、受講者自身の題材で1本書いてもらう |
| 35-50分 | 受講者が実際に送る → 結果を一緒に読む | うまくいかない箇所を、型のどこが欠けたか、で説明する。2〜3往復させる |
| 50-57分 | 第2回のテーマ決めと、コース選択（A/B） | 「何を作るか」をこの場で1つに決める。決まらない場合は講師が2案出して選んでもらう |
| 57-60分 | 宿題の説明・締め | 宿題：日常のことを3回、AIに聞いてみる。内容は問わない |

### 教材：指示の4点セット

未経験者に「プロンプトエンジニアリング」という言葉は使いません。次の4つだけを渡します。

```text
1. 目的  「何のために使うのか」  例：町内会の回覧板を作りたい
2. 相手  「誰が読むのか」        例：60〜80代の住民の方
3. 条件  「守ってほしいこと」    例：400字以内、専門用語なし、日付は9月15日
4. 形式  「どんな形で返すか」    例：そのまま印刷できる文章で
```

そのうえで、**「一度で完成させようとしない」**ことを伝えます。返ってきた文に対して
「もっと短く」「ここだけ変えて」と言い直すのが正しい使い方だ、と最初に握っておくと、
後から「思った通りにならない」で離脱しなくなります。

### この回で必ず伝える3つの注意

1. AIは間違えます。**事実（日付、金額、固有名詞、法令）は必ず自分で確認する**
2. 他人の個人情報、勤務先の機密情報は入力しない
3. 出てきた文章をそのまま公的な場に出す前に、一度自分の言葉で読み直す

### 遅れたときに削る箇所

- 20-35分の練習を10分に圧縮し、35分以降の往復を優先する（**手を動かす時間は削らない**）
- 宿題の説明はトークルームのテキストに回す

---

## 第2回：開発（60分）

**目的**：成果物を1つ、その場で完成させる。事前アンケートと第1回の結論でコースを決めておきます。

### コースA：文章・資料コース（既定）

想定題材：案内文、お知らせ、メール文面、説明資料の骨子、Excelの表の整理。

| 時間 | 内容 |
| --- | --- |
| 0-5分 | 宿題の共有。うまくいかなかった例を1つ聞き出す（ここが一番の教材になる） |
| 5-15分 | 今日作るものの完成イメージを言葉にする。「誰に渡して、どうなれば成功か」を確定 |
| 15-35分 | **受講者が主導で作る**。講師は詰まったところだけ介入する。ここは沈黙してよい時間 |
| 35-50分 | 出来上がったものを一緒に直す。「AIに直させる」と「自分で直す」の切り分けを実演 |
| 50-57分 | 完成物を、実際に使う場所（メール、Word、印刷）に移すところまでやる |
| 57-60分 | 第3回の予告：これを「毎回できる形」にする |

### コースB：Web公開コース（選択制）

想定題材：自己紹介ページ、教室・お店の案内ページ、作品の掲載ページ。

**未経験者向けに、インストール作業とコマンド操作は一切行いません。ブラウザだけで完結させます。**

| 時間 | 内容 |
| --- | --- |
| 0-5分 | 宿題の共有 |
| 5-15分 | 載せる内容を決める（名前、何をしている人か、連絡手段、写真1枚） |
| 15-30分 | AIにページの原稿とHTMLを作らせる。**中身を1行ずつ説明しない**。「ここが見出し」「ここが本文」だけ |
| 30-45分 | GitHubのアカウント作成 → ブラウザ上でファイルを置く → 公開設定 |
| 45-55分 | **公開されたURLを実際にスマートフォンで開いて確認する**（ここが最大の達成体験） |
| 55-60分 | 直したくなったときの直し方を1回だけ実演。第3回の予告 |

> 補足：公開までの流れは、講師自身が実際に運用しているサイト構築の手順を、未経験者向けに簡略化したものです。
> 「AIに書かせる → 人が確認する → 公開する → 直す」というループそのものが、この回で伝えたい本体です。

### この回で必ず伝えること

- **AIの出力をそのまま使わない**。必ず自分が読んで、1箇所は自分の言葉に直す
- 画像や文章の権利。他人の写真・文章をそのまま載せない。AIが生成したものにも用途上の注意がある
- 公開したものは他人が見る。個人情報をどこまで載せるかは自分で決める

### 遅れたときに削る箇所

- コースA：50-57分の「実際に使う場所へ移す」を口頭説明に切り替える
- コースB：**公開までは絶対に削らない**。15-30分の原稿づくりを講師主導に切り替えて短縮する

## 第3回：運用（60分）

**目的**：その場限りで終わらせない。3か月後も同じことができる状態にする。

| 時間 | 内容 |
| --- | --- |
| 0-5分 | 前回からの間に、自分で使ってみたか確認。使えていなくても責めない。理由を聞く |
| 5-20分 | **テンプレート化**。第1〜2回で使った指示文を、穴埋め式に書き換えて保存する |
| 20-30分 | 保存場所を決める（メモアプリ、ファイル、AI側の保存機能）。実際にそこへ置くまでやる |
| 30-40分 | **失敗パターンの見分け方**。下記チェックリストを使って、実際に誤りを含む出力を一緒に検証する |
| 40-50分 | よくある壁への対処：長い文章、表・数値、画像、複数のAIの使い分け |
| 50-57分 | **今後30日の計画**を一緒に書く。週1回、何に使うかを具体名で3つ決める |
| 57-60分 | 質問対応・締め |

### 教材：テンプレートの形

```text
【テンプレート名】お知らせ文を作る

目的：（　　　　　　　）のお知らせを作る
相手：（　　　　　　　）
条件：（　　）字以内 / 専門用語なし / 日付は（　　　　）
形式：そのまま印刷できる文章で

※ 出てきたら必ず確認すること：日付、金額、固有名詞、連絡先
```

これを3〜5本作って保存させます。**「毎回ゼロから考えない」状態にすることが、この回の成果物です。**

### 教材：出力を確認するチェックリスト

```text
□ 日付・曜日・時刻は合っているか
□ 金額・数量・単位は合っているか
□ 人名・団体名・商品名は実在し、表記が正しいか
□ 「法律で決まっている」「必ず〜です」と書かれた箇所の根拠を確認したか
□ 自分が読んで、意味が分かるか（分からない文は相手も分からない）
□ 他人の個人情報や、権利のある文章・画像が混ざっていないか
```

### 30日計画の書かせ方

抽象的な目標（「業務効率化する」）は書かせません。**動詞と対象を必ず入れさせます。**

```text
第1週：毎週月曜の（　　　　）の文章を、テンプレートで作る
第2週：（　　　　）の資料の下書きを、AIに作らせてから直す
第3週：（　　　　）を1つ、AIに相談してから決める
第4週：うまくいかなかったものを1つ持ち寄る（→ 追加相談の入口）
```

### 遅れたときに削る箇所

- 40-50分の「よくある壁」を、後日テキストで送る形に切り替える
- **テンプレート化（5-20分）と30日計画（50-57分）は削らない**。この2つが第3回の価値の本体です

---

## 事前準備（講師側・各回共通）

- 事前アンケートの回答を読み、当日の題材を1つに絞っておく
- 題材について、**講師が先に一度AIで通しでやっておく**（詰まる箇所を把握するため）
- 使う画面（AIの画面、必要ならエディタやGitHub）を開いた状態にしておく
- 個人的な通知、他の顧客名が映るタブは、画面共有前にすべて閉じる
- 終了後30分以内に、受講メモを送る（内容は `04-templates.md` を参照）
