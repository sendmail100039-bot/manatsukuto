## 2. 確定した設計

| 項目 | 決定内容 |
| --- | --- |
| 出品形態 | ビデオチャット（画面共有）によるマンツーマン授業 |
| 構成 | 1時間 × 3単位（第1回 導入 → 第2回 開発 → 第3回 運用） |
| ターゲット | AI未経験の個人 |
| ブランド | MANATSUKUTOとは切り離した**個人名義**の出品 |
| 価格 | 段階式ラダー（最低金額 → 2,000 → 3,500 → 5,000 → 7,000 → 9,000円） |
| 第2回の分岐 | A：文章・資料コース（既定）／ B：Web公開コース（選択制） |

### ブランドを分けた理由

ココナラは**プラットフォーム外への誘導・連絡先交換を禁止**しています。
出品文・トークルーム・レッスン中のいずれでも、MANATSUKUTOの名称、サイトURL、
メールアドレスを出さない前提で全原稿を書いています。個人の経歴（業務システム開発、
医療現場11年、電子カルテ導入支援、職員教育）は個人実績として記載可能です。

### 価格を段階式にした理由

ココナラは**出品後に価格を変更でき、過去の評価は価格を変えても残ります**。
これを利用し、最低金額で最初の評価3件を集めてから段階的に上げます。
60分マンツーマンの相場は5,000〜10,000円なので、最低金額は価格帯として突出し、
評価0件でも最初の購入が入ります。

## 5. ブロッカー

### この実行環境からココナラにアクセスできません

実測で確認済みです。

```
coconala.com          → CONNECT に 403（ERR_TUNNEL_CONNECTION_FAILED）
example.com           → 遮断
www.google.com        → 遮断
www.yahoo.co.jp       → 遮断
github.com            → 到達
registry.npmjs.org    → 到達
pypi.org              → 到達
api.anthropic.com     → 到達
```

**原因：** 環境のエグレスポリシーが許可リスト方式で、パッケージレジストリ・GitHub・
Anthropic API のみ許可、それ以外は全遮断。ココナラが名指しで拒否されているわけでは
ありません。プロキシのREADMEに「再試行も迂回もせず、遮断されたホストを報告せよ」と
明記されています。

curl でも Chromium でも同じ結果です（Chromium は `/opt/pw-browsers/chromium-1194` に
存在し起動もできますが、遮断は通信経路側にあるため結果は同じ）。

**ポリシーを緩めても解決しません。** ログイン必須のページなので、到達できるように
なっても西岡さんのログイン状態はこのコンテナに存在せず、未ログイン画面しか見えません。

**回避策：** 出品管理画面のスクリーンショット、またはテキストでの貼り付け。

## 7. 運用方針として決めたこと

次のセッションでも維持してください。

1. **評価・販売実績は正攻法で取得する。**
   対価を伴う購入（購入代金を別の形で補填する取引）、複数アカウントによる評価取得、
   評価内容の指定は行いません。プラットフォームの規約違反であることに加え、
   景品表示法のステマ規制（2023年10月施行）に該当し得る類型であり、
   措置命令の対象は事業者側になります。集客のためのリスクとして割に合いません。

2. **MANATSUKUTOのブランド・サイト・連絡先は、ココナラ上に一切出さない。**

3. **できないことを出品文に書かない。**
   「システムの構築、アカウント連携の設定代行は含みません」を免責に明記済み。
   タイトルに「自動化します」を使う場合は、この免責と衝突するため要調整。

4. **専門領域の線引き。**
   医療・法律・税務・会計の個別助言は行わない。AIの出力の正確性は保証しない。
