# 運営手順

## 1. 規約上の注意（出品前に必ず確認）

［要確認：ココナラの利用規約・禁止事項は改定されます。出品前に最新版を確認してください］

| 項目 | 対応 |
| --- | --- |
| **外部への誘導の禁止** | 出品文、トークルーム、レッスン中のいずれでも、自社サイト名・メールアドレス・SNS・電話番号を出さない。受講メモにも記載しない |
| **プラットフォーム外での直接取引の禁止** | 「次回は直接で」という提案は、受講者側から出た場合も断る。断り文面は `04-templates.md` に用意 |
| **成果の保証表現** | 「必ず稼げる」「業務時間が半減します」などの断定は書かない。本原稿では意図的に避けている |
| **資格が必要な領域** | 医療・法律・税務・会計の個別助言は行わない。相談された場合は「その分野の専門家へ」と案内する |
| **他者の権利** | レッスンで扱う題材に、第三者の文章・画像・ロゴを持ち込ませない。生成物の利用範囲についても第2回で触れる |
| **録画・記録** | 録画はしない方針。受講者から録画を求められた場合の対応を事前に決めておく ［要確認：プラットフォーム側の規定］ |

**MANATSUKUTOのブランド・サイト・連絡先は、ココナラ上では一切出しません。**
個人の経歴（業務システム開発、医療現場での勤務、電子カルテ導入支援、職員教育）は、個人の実績として記載して差し支えありません。

## 2. 購入から完了までの流れ

```
購入
 ↓ （当日中）
お礼と事前アンケート送付         → 04-templates.md「A. 購入直後」
 ↓ （回答受領後24時間以内）
日程調整・題材の確定             → 04-templates.md「B. 日程調整」
 ↓ （前日）
リマインドと準備物の再確認       → 04-templates.md「C. 前日」
 ↓
レッスン実施（60分）             → 02-curriculum.md
 ↓ （終了後30分以内）
受講メモ送付                     → 04-templates.md「D. 受講メモ」
 ↓ （翌日）
フォローと次回のご案内           → 04-templates.md「E. フォロー」
 ↓
クローズ・評価依頼               → 04-templates.md「F. 評価依頼」
```

**返信の目安**：購入・質問には**12時間以内**に一次返信。当日中に返せない時間帯がある場合は、
出品文の「購入にあたってのお願い」に対応可能時間帯を書いておくと評価が下がりません。

## 4. 実績ゼロからの立ち上げ計画

評価0件が最大の障壁です。順序を守ってください。

**第1段階：出品準備（1〜2日）**

1. `01-service-listing.md` の原稿を貼り、価格を **5,000円** に設定
2. 出品画像を作成（文字要素3つ、単色背景）
3. プロフィールを埋める。**本人確認とNDA（機密保持契約）の設定を済ませる** — 未設定は購入検討時の減点要因です ［要確認：現在の呼称と設定場所］
4. 出品を公開

**第2段階：最初の3件（〜1か月）**

- 出品文の冒頭に「**開始記念価格**」と明記し、期限を切る（値上げの根拠になります）
- 受講後アフター相談（14日間テキスト）を**無料特典**として本文に書く
- 質問が来たら、購入前でも丁寧に答える。ここでの応答が購入の決め手になります
- 完了ごとに、必ず評価を依頼する（`04-templates.md`「F」）

**第3段階：評価10件（〜3か月）**

- 価格を **7,000円** へ改定
- 無料特典だったアフター相談を**有料オプション化**
- 実際の受講者の悩みの言葉を、出品文の「こんな方に向いています」に反映する
- 質問が多かった内容を、そのままFAQに追記する

**第4段階：横展開**

- 「Web公開コース」を単独の出品として切り出す（単価を上げやすい）
- 3コマ一括の出品を追加する
- リピートが月3件を超えたら 9,000円へ

## 5. 価格を上げる判断基準

次の**3つすべて**を満たしたときにだけ上げます。

1. 評価が10件以上あり、平均★4.8以上
2. 直近1か月の購入が3件以上
3. 「時間内に終わらなかった」が2回連続で発生していない（＝内容が価格に見合っている）

3を満たさないまま値上げすると、評価が下がって元に戻せなくなります。

## 6. 想定トラブルと対応

| 状況 | 対応 |
| --- | --- |
| 受講者が接続できない | 開始5分は接続対応に充てる前提で組む。それでも繋がらない場合は日程を振り替える（追加料金なし） |
| 受講者の操作が遅く、進まない | 到達点を1つに絞る。「今日は指示を1本書けたら成功」と目標を下げて宣言する。中途半端に全部やらない |
| 想定外の質問（税務・法務・医療） | 「その分野は専門家の判断が必要な領域なので、こちらでは回答しません」と明確に線を引く |
| 受講者が機密情報を画面に出した | すぐに指摘して閉じてもらう。見た内容は記録せず、メモにも残さない |
| 外部での直接取引を持ちかけられた | 断る（`04-templates.md`「G」）。規約違反はアカウント停止のリスクがあり、割に合いません |
| 低評価が付いた | 反論しない。事実誤認があれば穏当に補足するのみ。同じ指摘が2回出たら出品文かカリキュラムを直す |
| 時間内に終わらなかった | 講師側の見積り責任として、初回は延長料金を取らずに10分延長。3回続いたらカリキュラムを削る |

［要確認：手数料率22%（税込）は改定されます］

| 価格 | 手数料22% | 手取り | 実作業（準備40分＋本番60分＋事後20分） | 実質時給 |

## 8. 「いまの使い方」を教材に変換する運用

このサービスの中身は、講師自身が日常的にやっていることの縮約です。
新しく身につけるのではなく、**すでにやっていることを切り出す**のが、教材更新の基本方針です。

| 実際にやっていること | レッスンでの見せ方 |
| --- | --- |
| AIに目的と条件を渡して文章・資料を作らせる | 第1回「指示の4点セット」 |
| 出てきた出力を人が確認してから使う | 第1回の注意3点、第3回のチェックリスト |
| ブラウザからGitHubにファイルを置いて公開する | 第2回コースB |
| 手順を書き残して再利用する | 第3回のテンプレート化 |
| 用途に応じて複数のAIを使い分ける | 第3回「よくある壁」 |

**運用ルール**：自分の作業で「同じ指示を2回以上書いた」ものは、テンプレート化して教材候補に入れる。
月1回、直近の受講で出た質問と合わせて `02-curriculum.md` を見直します。
