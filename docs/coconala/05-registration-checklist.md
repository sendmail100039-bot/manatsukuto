# 出品登録シート（上から順に貼るだけ）

登録作業中に迷わないよう、**判断を全部このファイルに先出し**しています。
`01-service-listing.md` の複数案から、推奨案を1つに確定させた版です。

> 画面の項目名はココナラ側の変更で本シートと異なる場合があります。
> 近い意味の項目に読み替えてください。

---

## 第0段階：出品前に済ませること

出品フォームに入る前にこれらが未完了だと、途中で中断することになります。

- [ ] ココナラのアカウント登録（メールアドレス）
- [ ] **本人確認**の提出 ［購入検討時に「本人確認済み」表示があるかどうかで信頼度が変わります］
- [ ] **機密保持契約（NDA）**の設定 ［同上。設定すると出品ページにバッジが出ます］
- [ ] 売上の**振込先口座**の登録
- [ ] プロフィール本文（下の「プロフィール貼り付け用」を使用）
- [ ] プロフィール画像 ［顔写真でなくても可。ただし初期設定のままは避ける］

## 第1段階：出品フォーム

### ① カテゴリ

```
学習・就職・資格・コーチング  >  パソコン・スマホ・家電の使い方
```

見当たらなければ `IT・プログラミング・開発` 内のAI関連カテゴリへ。
**迷ったら学習系を選ぶ**（未経験の個人が探す場所だからです）。

### ② サービスタイトル

```
AI未経験OK｜60分であなたの作業を1つ自動化
```

25文字。文字数上限で弾かれた場合の短縮版：

```
AI未経験OK｜60分で作業を1つ自動化します
```

### ③ キャッチコピー

```
1回目で使える、2回目で作れる、3回目で続けられる
```

### ④ サービス内容（本文）

`01-service-listing.md` の「4. サービス内容（本文）」のコードブロックを**全文コピー**してください。
文字数上限で入りきらない場合、削る順序は次のとおりです。

1. 「■ 担当者について」を3行に圧縮
2. 「■ ご用意いただくもの」を「購入にあたってのお願い」欄へ移動
3. 「■ 進め方」の4ステップを2行に圧縮

**「■ こんな方に向いています」と「■ 3回で〜」は削らないでください。** ここが購入判断の中心です。

### ⑤ 価格

```
出品画面で設定できる最低金額（500円程度） ［要確認］
```

段階式の価格ラダーの**第0段**です。評価3件が付いた時点で2,000円に上げます。
全6段の一覧と各段の条件は `01-service-listing.md`「7. 価格設定」にあります。

> 第0段に入る前に、`06-rehearsal-agreement.md` のリハーサル研修を済ませてください。
> 最低金額の枠は一度しか使えないので、カリキュラムが固まる前に消費しないことです。

### ⑥ お届け日数 / 納期

```
7日
```

（購入 → 事前アンケート → 日程調整 → 実施、で1週間を見込みます）

### ⑦ 購入にあたってのお願い

`01-service-listing.md` の「5. 購入にあたってのお願い」のコードブロックをそのまま貼り付け。

**貼った後に1箇所だけ埋めてください：** 対応可能な曜日・時間帯を追記します。

```
・対応可能な時間帯：（例：平日 20:00〜22:00 / 土日 10:00〜18:00）
```

### ⑧ 有料オプション

まずは**1つだけ**設定します（多いと購入前に迷わせるため）。

| 項目 | 値 |
| --- | --- |
| オプション名 | `延長30分` |
| 価格 | `3,000円` |
| 追加日数 | `0日` |

残り3つ（事前設定サポート、テンプレート集作成、アフター相談）は、
評価が5件を超えてから追加してください。

### ⑨ 提供形式

```
ビデオチャット
```

［要確認：通常出品でビデオチャットを使う設定なのか、電話相談カテゴリでの分単位課金なのかを画面で確認してください。
**後者だと本シートの価格設計（1コマ固定5,000円）が成立しません。** その場合は連絡をください、分課金用に組み直します］

### ⑩ 出品画像

`01-service-listing.md`「9. 出品画像の方針」に沿って作成。要素は3つだけです。

```
AI、はじめてでも。
画面共有マンツーマン 60分
導入 → 開発 → 運用
```

画像がまだない場合、**先に文字だけの画像で公開してしまって構いません**。
未公開のまま作り込むより、公開して反応を見る方が早く進みます。

### ⑪ タグ

```
ChatGPT / AI / 生成AI / AI初心者 / パソコン教室 / マンツーマン / 画面共有 / 個人レッスン / 業務効率化
```

上限数がある場合は左から順に採用してください。

## プロフィール貼り付け用

出品ページとは別に、プロフィール欄にも記載が必要です。
**MANATSUKUTOの名称、サイトURL、メールアドレスは書かないでください**（外部誘導とみなされる可能性があるため）。

```text
はじめまして。AI・デジタル活用のサポートをしています。

企業向け業務システムの開発・導入支援に携わったのち、医療現場で11年以上勤務しました。
現場では電子カルテの導入支援、業務ソフトの開発・運用、職員向けの教育を担当しています。

「詳しい人が使いこなす」ためのAIではなく、
「これまで触ったことのない人が、明日も同じことをできる」ようにすることを大事にしています。

専門用語を使わず、画面をお見せしながら、その場で手を動かしていただく進め方です。
分からないことが多い段階でのご相談を歓迎しています。

※ AIの出力内容の正確性を保証するものではなく、必ず人が確認する前提でお伝えしています。
※ 医療・法律・税務・会計に関する個別の判断や助言は行っていません。
```

## 登録中に確認して、こちらに戻してほしい情報

以下が分かれば、原稿の ［要確認］ を実際の仕様に合わせて修正します。
**この実行環境からはココナラに接続できない**（ネットワークポリシーで遮断されています）ため、
画面を見られるのは西岡さんだけです。

1. タイトル・キャッチコピー・本文それぞれの**文字数上限**
2. 実際のカテゴリ階層の名称（本シートの候補が存在するか）
3. ビデオチャットが**固定価格の通常出品で使えるか**、分単位課金の別カテゴリか
4. 有料オプションの**設定可能数**
5. 販売手数料の**現在の料率**（本シートは22%（税込）で計算しています）
6. タグの**登録可能数**

画面のスクリーンショットや、項目名をそのまま貼っていただければ、こちらで原稿を合わせ込みます。
