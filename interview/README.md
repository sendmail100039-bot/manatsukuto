公開リポジトリであるこのリポジトリでは管理していません。

## リポジトリを非公開にする場合の注意

このリポジトリはGitHub Pages（`site/`）で公開サイトを配信しています。
無料プランでprivateに変更すると **Pagesの公開が停止** し、
https://sendmail100039-bot.github.io/manatsukuto/ が表示されなくなります。

サイトを公開したまま面接用デッキを非公開で管理する場合は、別のprivateリポジトリに置いてください。
